# Indoinves Global Portal & Blog Automation

Indoinves is an authoritative digital publication platform delivering high-impact news, macroeconomic analysis, financial market intelligence, and structural business insights to a worldwide readership.

This repository contains the core HTML frontend (`index.html`), automated Python generation scripts, and complete category directories designed for seamless deployment on GitHub Pages.

---

```text
├── index.html         # Main portal page displaying the complete 68+ category grid

│   ├── finance/       # Category: Finance & Banking

│   ├── tech/          # Category: Technology & AI
│   └── ...            # (Total 68 complete category channels)
